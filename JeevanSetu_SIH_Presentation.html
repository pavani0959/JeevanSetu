Proposed Solution

How JeevanSetu Works

  • Sensor Input: IoT rain gauge, soil moisture probe, stream sensor → data every 3 sec with live ±2 jitter (simulates real sensor noise)
  • Risk Engine: Rainfall (40pts) + Soil (25pts) + Stream (20pts) + Terrain (15pts) → Ward Score 0–100, fully explainable
  • State Classification: NORMAL / WATCH / WARNING / CRITICAL → auto-triggers downstream action layer
  • Propagation Model: Ward 1 (source, 1240m) → Ward 3 (Riverside, 760m) → Ward 4 (Nala Basin, 620m) — upstream cascade
  • Infrastructure Engine: East Bridge CLOSED, North Road safe route arrow activates, Shelter STANDBY→PREPARING→OPEN
  • Vulnerable POI Priority: School 340 children (EVACUATE FIRST), Health Sub-Centre 45 patients (EVACUATE FIRST), Anganwadi (NOTIFY)
  • Bilingual Alert: English + Hindi (Noto Sans Devanagari), flash on CRITICAL, slide-down on WARNING
  • Acknowledgement Chain: Volunteer notified → Coordinator ack → District Response Team → Priority evacuation flagged
  • Offline-First: Custom SVG map (zero tile dependency), cached data → fully functional with NO internet
  • Live Dashboard: 5-ward map, telemetry bar, arc gauge, 30-min sparklines, vulnerable counts — all in < 3 seconds

Scalability & Real-World Deployment

Prototype → Production
in 3 steps

1
Hardware Integration — 3 months
Replace simulated data with real IoT sensors: IMD rain gauges, CWMS stream sensors, capacitance soil probes → pipe live readings into the existing risk engine via REST API. No frontend changes needed.
2
ML Model Upgrade — 4 months
Replace rule-based engine with trained model: IMD historical rainfall (50 years) + NDWI satellite imagery + CWC stream records → XGBoost / LSTM for improved prediction accuracy and 30-min advance warning.
3
SMS / IVR Alert Integration — 2 months
Replace simulated alert feed with real communications: Twilio / Gupshup SMS API → volunteer phones. IVR calls in Hindi for feature-phone users in zero-connectivity zones. Government alert gateway integration.
Replicable across any hilly district in India — the same risk engine, same dashboard, different ward/sensor data.
